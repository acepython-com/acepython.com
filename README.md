# acepython.com

Premium Django Security Education & Production-Ready Code Templates

## 🎯 Mission

Help Python developers build secure, production-ready Django applications through comprehensive courses and battle-tested code templates.

## 📚 What We're Building

### Courses (Phase 1)
1. **Acing Django Security** - 5 units covering Django's built-in security, account security, execution security, deployment/infrastructure, and API/integration security
2. **API-Driven Django** - DRF authentication, rate limiting, CORS, JWT
3. **Civic Data Engineering** - Data scraping, public records, civic data automation
4. **ActivityPub for Developers** - Building federated social apps
5. **Code Samples Library** - Individual purchases + packs

### Code Template Library
- Authentication boilerplate
- API security patterns
- Deployment configurations
- Testing frameworks
- Security audit scripts

## 📖 Course Structure

Each course includes:
- 🎥 Video lectures (10-15 min each)
- 💻 Hands-on code examples
- 📝 Interactive exercises
- ✅ Quizzes and assessments
- 📚 Additional resources

## 🛠️ Tech Stack

- **Framework:** Django 4.2+
- **Python:** 3.10+
- **Database:** PostgreSQL (production), SQLite (development)
- **Testing:** pytest-django, factory_boy
- **Deployment:** Docker, GitHub Actions, Heroku/Render
